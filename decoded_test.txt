This is a test file for the QRL application.

QRL (QR Code Data Exfiltration) is a proof-of-concept tool that demonstrates
how data can be exfiltrated through animated QR codes displayed on screen.

The system works by:
1. Chunking data into small pieces
2. Encoding each chunk into a QR code
3. Displaying the QR codes in sequence
4. Capturing and decoding the sequence on another device

This is for educational and authorized security testing purposes only.
