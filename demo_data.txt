This is a demonstration file for testing the parallel QR encoding system.

The new parallel encoding system can split data across multiple independent QR streams,
allowing for dramatically faster data transfer rates. Instead of being limited by
the capacity of a single QR code (around 1-3KB depending on error correction),
we can now use multiple QR codes simultaneously.

Key advantages:
1. Bypasses single QR size limitations
2. 4x to 16x speed improvements with parallel streams
3. Independent stream processing for better reliability
4. Backward compatible with traditional single-stream encoding

Technical details:
- Each stream carries its own sequence numbers and metadata
- Streams can be processed independently by multiple scanners
- Data is automatically split across streams for optimal load balancing
- Client can reassemble streams in any order as they complete

Performance examples from testing:
- 50KB file: 3.9x speedup with 4 streams, 11.7x with 16 streams
- 100KB file: 3.8x speedup with 4 streams, 13.8x with 16 streams
- 500KB file: 4.0x speedup with 4 streams, 15.6x with 16 streams

The system maintains full data integrity while dramatically improving throughput.
This makes QR-based data transfer practical for much larger files than
was previously possible with traditional single-stream QR encoding.
